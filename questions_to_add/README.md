# Questions To Add

Drop your files into this folder!

### Supported Formats:
You can drop files in any format, for example:
- Text & Notes: .txt, .md
- Spreadsheets & Data: .csv, .json, .xlsx
- Documents & PDFs: .pdf, .docx
- Images / Screenshots: .png, .jpg, .jpeg

---

### How to Use:
1. Copy or save your files into this folder (questions_to_add/).
2. Message me in chat: "I added the files, please process them and add them to the website."
3. I will read your files, extract and format the questions (including KaTeX math formatting, domains, topics, options, correct answers, and explanations), and integrate them directly into the website's question database!
