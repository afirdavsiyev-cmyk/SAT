# Videos To Add

Drop your video files into this folder!

### Supported Formats:
You can drop video files in any standard format:
- **MP4:** .mp4 (Recommended for web compatibility)
- **WebM:** .webm
- **MOV / QuickTime:** .mov
- **Other video files:** .mkv, .avi, etc.

---

### How to Use:
1. Copy or save your video files into this folder (ideos_to_add/).
2. Message me in chat telling me where or how you would like them used on the website (for example:
   - *"I added lesson videos for Algebra"*
   - *"Add this video as an explanation for question alg-exp-001"*
   - *"Put this video walkthrough on the landing page/dashboard"*).
3. I will access the videos, configure them for the website (placing them in public/videos/ so the browser can serve them), and integrate video players or links into the website components!
